# Программная система оформления заказа обуви ООО «Чудо Обувь»

## 1. Название приложения
Информационная система каталога и оформления заказов **«Чудо Обувь»** (разработана в рамках демонстрационного экзамена КИМ 09.02.07-2).

## 2. Используемые технологии
- **Язык программирования:** Python 3 (стандарт именования `snake_case`)
- **Графический интерфейс:** Tkinter (`ttk`) в соответствии с руководством по стилю (`Calibri`, `#FFFFFF`, `#D2F6E7`, `#70B2AF`, подсветка остатков `<= 3` цветом `#ff8080`)
- **СУБД:** SQLite 3 (база данных в 3НФ `chudo_obuv.db`, скрипт `chudo_obuv_dump.sql`)

## 3. Основные функции системы
1. **Просмотр каталога обуви:** вывод изображения, категории, наименования, производителя, состава, цены с учётом автоматической скидки 25% (для моделей без заказов за прошлый месяц) и суммарного остатка по всем размерам.
2. **Подсветка малого остатка:** товары с суммарным остатком 3 пары и менее автоматически выделяются светло-красным фоном (`#ff8080`).
3. **Авторизация по логину:** вход для ролей `Авторизованный пользователь`, `Менеджер` и `Администратор` с выводом ФИО в правом верхнем углу окна.
4. **Поиск, фильтрация и сортировка в реальном времени:** одновременный поиск по названию и описанию, фильтр по категории (включая пункт «Все категории») и сортировка по возрастанию/убыванию цены.
5. **Оформление и управление заказами:** создание заказа с выбором размера и количества, просмотр состава заказа, удаление и редактирование заказов для Менеджера и Администратора.

## 4. Порядок подготовки базы данных и запуска приложения
1. База данных `chudo_obuv.db` уже создана и заполнена импортированными данными (при необходимости пересоздаётся из `chudo_obuv_dump.sql`).
2. Для запуска приложения выполните:
   ```bash
   python main.py
   ```
