## Задача на поиск ошибки
**Вопрос:** Почему при `PRAGMA foreign_keys = OFF;` вставка `INSERT INTO orders (id, client_id) VALUES (1, 999);` проходит без ошибки, хотя клиента 999 нет?
**Ответ:** Потому что в SQLite проверка внешних ключей отключена (`OFF`). Когда `PRAGMA foreign_keys = OFF`, SQLite просто игнорирует ограничения `REFERENCES` и позволяет вставить любое число, создавая «записи-сироты».

## Задача на предсказание результата
**Вопрос:** У клиента `id = 1` есть два заказа (`id = 1` и `id = 2`). Что произойдёт при `DELETE FROM client WHERE id = 1;` с `ON DELETE CASCADE`?
**Ответ:** Из таблицы `client` удалится строка клиента `id = 1`, и одновременно из таблицы `orders` автоматически (каскадно) удалятся оба его заказа (`id = 1` и `id = 2`).
