## Задача на поиск ошибки
**Вопрос:** Студент написал `CREATE TABLE student (id INTEGER, fio TEXT, birth TEXT);`. Почему `id` не будет автоматически увеличиваться?
**Ответ:** Потому что не указано ограничение `PRIMARY KEY` (или `INTEGER PRIMARY KEY AUTOINCREMENT`). В SQLite автоинкремент работает только для столбца, объявленного как `INTEGER PRIMARY KEY`. Без этого при вставке без указания `id` в поле просто запишется `NULL`.
